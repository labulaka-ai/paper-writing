# Introduction

本节按「功能模块＋语言力学」法组织。语言细节统一查 language-mechanics.md，此处只列本节最吃紧的几项。

## 功能模块与写作流程（本法）

经典漏斗四步，从宽到窄：

1. **确立领域重要性**（Establish significance）：开头第一句千万不要直接说「我要研究什么」。先告诉读者这个领域为什么重要、为什么有价值——可强调问题有多普遍、材料有多大的经济价值、或该领域近年研究有多火热。
2. **提供背景事实与文献回顾**（Provide background & literature review）：由浅入深，先写大家都知道的公认事实，再引用具体文献。不要为了引用而引用——这里的引用是为读者看清前人做了哪些贡献、为下一步找 gap 做铺垫。
3. **指出研究空白或问题**（Locate the gap / Identify the problem）：引言最关键的一步。不能凭空说「我要做这个」，要说「因为前人没做好（或没做过），所以我要做」。通过转折词（如 However, Although）指出前人研究的不足、未解决之处或尚未探索的领域，让研究动机自然引出。
4. **介绍本文工作**（Describe the present paper）：在漏斗底部推出自己的研究——针对上述空白，用了什么方法、达到什么目的、论文如何组织。

**分段规则**：一段只讲一个核心观点；每段第一句必须是主题句（Topic Sentence），告诉读者这段讲什么，后面的句子围绕主题句展开（讨论、举例、描述）。

## 语言力学要点（本法）

- **引用时态即态度**：把过去的研究写成现在时，意味着你默认这是公认真理；写成过去时，表示这仅是当时的研究结论。改变时态，就改变了读者对结论可靠性的认知。引用前先想清楚你要给读者的态度。
- **禁用无施动者被动**：引言中用 agentless passive（如 X is presented、The data were analyzed...）会让读者分不清动作是谁发出的——引言必须严格区分「前人的贡献」和「本文自己的工作」，模糊的被动很危险。解法是用**替身主语**：描述本文工作时用主动语态，主语指代论文本身——`This paper presents a set of criteria...` / `The present study describes the preparation of...`；不要写 `A set of criteria is presented...`（谁呈现的？不清楚）。（注：无施动者被动在 Methodology 与 Results 中是标准写法，只在引言里是缺陷——分节规则见 language-mechanics.md。）
- **We 的用法**：`We` 只指自己的研究团队（如 `We have developed...`）；泛指「人们普遍认为」不许用 `We know that...`，写 `It is known/thought that...`。
- **连接词**：句与句之间是「危险地带」，必须用 signalling language 标明逻辑关系；走到第三步 gap 时，However 和 Although 能瞬间让读者明白「铺垫结束，作者要提问题了」。分类表与误用警告（句首不用 so；conversely 蕴含一对一错）见 language-mechanics.md。

## 结构补强

**CARS 三步模型**（Swales 1990）——与本法漏斗同构，可作逐步施工版：

- **Move 1 立领域**：claim centrality（为什么领域现在关心）／topic generalizations（公认的一般事实）／review prior work（综述前人发现，要综合不要罗列）。纪律：Move 1 中每个关于领域的断言都必须能回溯到文献检索报告，没有引用的 centrality 断言是装饰，会在完整性闸门被标出。
- **Move 2 立缺口**：四种合法形态选一——indicate a gap（人群/场景/机制/方法未被覆盖）、counter-claim（前人结论冲突且未解决）、raise a question（已知事实解释不了观察到的模式）、continue a tradition（既有路线许可下一步）。**gap 必须被综述许可**：综述不支持「X 在 Y 中没人研究过」时，只能收窄为综述支持的版本（如 "evidence in Y remains limited to Z designs"），或回去补检索——绝不制造 gap。避开**全称否定陷阱**：`No study has examined X` 不可验证且是常见的 desk-reject 刺激点；改用限定范围的否定（点名数据库、时段、研究设计范围）或正面表述当前证据的边界。
- **Move 3 占位**：announce purpose（一句、主动、具体——`This study estimates...`，不要 `This study aims to explore...`）→ state RQs/hypotheses（与全文配置记录**逐字一致**，不许换述）→ preview contribution（读者读完将知道什么现在不知道的）→ outline structure（可选，多数 venue 已不写，模板要求时才加）。
- **目的句纪律**：目的句是同行评审中最被引用的一句。先写目的句、再写引言其余部分，并检查它是否精确回应 Move 2 的缺口——缺口讲 mechanism、目的讲 prevalence 这种 niche-purpose mismatch，审稿人一眼看穿。
- **比例**：引言约占正文 10–15%；Move 1 最宽，Move 2 最短最锋利，Move 3 对「做了什么」要具体且不弱化（弱化留给发现，不留给行动）；默认一段一个 move，Move 1 可占两段。
- **常见失败表**：漏斗过宽（"Since ancient times" 式开局）→ 从仍能显示 stakes 的最窄上下文起笔；文献倾倒（"A found X. B found Y." 式罗列）→ 按主题或张力综合；findings leak（引言里把结果讲全）→ 只预告贡献类型，数字留给 Results（除非学科惯例要求宣布发现）。

**引言结构卡**：

- 默认漏斗：`important problem -> specific phenomenon or difficulty -> what prior work establishes -> exact unresolved gap -> research question or hypothesis -> present study`
- 典型 4 段分工：①立领域 stakes（面向 Nature/Science 这类宽受众时要让非专家也能落地）②快速收窄到具体现象、张力或瓶颈 ③综述前人已解决与未解决的（综合，不罗列）④给出确切未知与研究问题，并说明本文如何处理——预告研究路线，不细讲 Results。
- 两条同向的纪律：gap 要定义为未知、有争议的条件、机制或边界，**不要定义为「作者的方法尚不存在」**；从 Results 的主张倒着写引言——引言的每个核心问题都要有 Results 的回答，每个核心 Results 主张都要有引言里的问题为它铺垫。

**标题**：标题三职——retrieval（检索）、screening（读者决定是否打开）、framing（设定主张的抱负等级）。起草 3–5 个候选用清单选：核心概念前置（前 3–4 词承载主题）；含本领域检索者真正会打的词（与摘要关键词对齐）；目标 ≤15 词（venue 惯例更长时从其惯例）；无未普及缩写；不用 "A study of"、"An investigation of"、"Toward an understanding of" 这类空壳开头；主张等级与研究设计匹配（横断面数据不许用因果动词）；具体到能排除「不是它的那五十篇论文」。

## ML/CV 与 venue 注记

- **方法型论文的引言变体**：漏斗之外另有成套变体，按材料选型并说明选型理由——task-then-application（先抽象定义任务，再展示应用）、application-first（从具体应用或痛点开场，收窄到任务）、general-to-specific-setting（宽领域→具体子问题）、open-with-challenge（以未解难题开场）、novel-task-challenge-decomposition（定义新任务并分解其挑战）、technical-challenge（1–3 变体，围绕技术瓶颈组织）、pipeline-version（1–4 变体，模块/管线型论文按模块框定贡献）。
- **会议稿的引言构成**：开场 1–2 句钩子（问题动机）→ 用 "However,..." 明说 gap → 贡献写成编号或项目符号清单 → 结尾给简短 roadmap（"The rest of this paper is organized as..."）；篇幅允许时放入主结果图（teaser）；目标约 1.5 页。
- **审稿人读法**：审稿人按标题→摘要→图→引言跳读，引言第一段与 teaser 图的权重高于正文中段，漏斗第一步的 stakes 必须对非本子领域审稿人也成立。
- CVPR 等双栏会议稿：引言通常与 Related Work 分工——Related Work 独立成节（按机制分组、每组末尾定位本文，见 discussion.md 与 gates.md 的相关检查），引言的文献回顾相应收窄，不要在引言里把 Related Work 写一遍。

## 本节自检清单

- [] 第一步：第一句不是「我要研究什么」，领域重要性对非本子领域读者也成立
- [] 第二步：背景由浅入深（公认事实→具体文献），每处引用都在为 gap 铺垫，无为引而引
- [] 第三步：gap 由 However/Although 类转折明确标出，且被前面的文献综述许可（无凭空制造、无全称否定）
- [] 第四步：本文工作（方法、目的、组织）说清；目的句精确回应 gap（无 niche-purpose mismatch）
- [] 每段一段一观点、首句即主题句；只读各段首句能连成连贯的缩小版引言
- [] 引言中描述本文工作无一处无施动者被动，替身主语（This paper presents…）到位
- [] 引用时态与态度一致：公认事实用现在时、仅当时结论用过去时
- [] We 只指自家团队；泛指人类知识用 It is known/thought that...
- [] 标题过清单：核心概念前置、≤15 词（或 venue 惯例）、无空壳开头、主张等级与设计匹配
- [] 引言长度在预算内（正文 10–15%）
